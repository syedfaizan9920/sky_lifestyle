# Sky Lifestyle

**Style Starts Here.** A responsive fashion and lifestyle storefront for the Indian market, built with Next.js App Router, TypeScript, and Tailwind CSS.

## Run locally

1. Install Node.js 20.9 or newer.
2. Install dependencies with `npm install`.
3. Start the development server with `npm run dev`.
4. Open [http://localhost:3000](http://localhost:3000).

Useful checks:

```bash
npm run lint
npm run typecheck
npm run build
```

## Phase 1

The storefront includes a demo product catalog, category and search listings, product detail pages, and a browser-persisted shopping cart. Products, prices, and imagery are illustrative demo content; there are no customer reviews, sales claims, payment processing, authentication, or admin tools.
